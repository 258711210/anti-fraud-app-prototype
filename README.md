# 反诈守护 · SP1 高保真交互原型

纯前端实现，零后端依赖。**直接双击打开 `index.html` 即可体验全部交互**（无需启动服务器）。

## 目录结构

```
prototype/
├── index.html        # 入口（手机壳框架 + SVG图标库）
├── css/style.css     # 设计系统（信任蓝/守护绿/警示橙/危险红，适老大字体）
├── js/data.js        # 模拟数据（诈骗类型、题库、等级、信用、商品、订单等）
├── js/app.js         # SPA路由 + 25个页面渲染与全部交互逻辑
└── assets/logo.svg   # 应用图标
```

## 可体验的完整流程（对应PRD章节）

| 流程 | 入口 | 覆盖需求 |
|---|---|---|
| 隐私协议 → 登录 | 启动自动弹出 | §4.1-4.2 一键/验证码(60s冷却)/微信登录 |
| 身份选择 | 登录后 | §4.4.1 求助者/守护者双身份 |
| 守护者三步认证 | 选守护者 | §4.4.2 实名活体(眨眼/张嘴/点头) → 能力标签 → 5题测评(80%合格线，含失败重测) |
| 视频求助 | 首页红色大按钮 | §7.2 选类型 → 权限申请 → 60秒匹配倒计时(可演示超时) → 模拟视频通话(计时/静音/翻转/字幕/录音横幅) → 五星评价(正负面标签切换) |
| 守护者守护 | 工作台开启在线 | §6.7/7 守护请求弹窗 → 接听 → 服务完成积分结算(基础分×等级加成) |
| 等级体系 | 我的/工作台 | §5.3 五级成长，双指标进度条，加成系数 |
| 信用中心 | 我的/工作台 | §6 信用分环图、S-D等级权重、双维构成、加减分明细 |
| 积分商城 | 底部导航 | §8 分类筛选、详情、兑换(实物选地址/虚拟发码)、积分不足与售罄异常、订单状态流转、物流追踪、取消退积分 |
| 地址管理 | 我的（守护者） | §8.3.7 增删改、默认地址 |
| 客服中心 | 我的→客服中心 | §7.3.5 **两种身份均可**看到申诉通道（4类）+ 联系客服（96110 + 在线客服） |
| 举报诈骗线索 | 首页快捷入口 / 我的 | 两种身份均可举报，选类型+描述+证据+联系方式 |
| 注销账号 | 我的 | 两步确认（原因选择→输入"确认注销"），注销后清除全部数据 |
| 身份切换 | 我的→切换身份 | 求助者⇄守护者，首次切换为守护者需完成三步认证 |

## 身份权限差异

| 功能 | 求助者 | 守护者 |
|---|---|---|
| 底部导航 | 首页 · 消息 · 我的（3tab） | 工作台 · 积分商城 · 消息 · 我的（4tab） |
| 积分商城 | 不可见 | 可见 |
| 兑换订单/收货地址 | 不可见 | 可见 |
| 客服中心 | 申诉通道 + 联系客服 | 申诉通道 + 联系客服 |
| 举报诈骗线索 | 可用 | 可用 |
| 注销账号 | 可用 | 可用 |
| 切换身份 | 可切换为守护者（首次需认证） | 可切换为求助者 |

## 演示提示

- 短信验证码统一为 **246810**（任意6位数字均可通过）
- 等待匹配页默认 5 秒后模拟接通，页面底部可单独演示「60秒超时」分支
- 守护者上线后 8 秒自动来单，也可点「立即模拟一笔守护请求」
- 「我的 → 切换身份」可随时切换求助者/守护者视角复测两条主线；首次切换为守护者需完成三步认证
- 求助者模式下不显示积分商城相关功能（底部导航、兑换订单、收货地址均为守护者专属）
- 浏览器窗口 >460px 时展示手机外框，窄窗口自动切换为全屏模式
